# Восстановление карточки Monitoring v2 (2025-11-19)

## Симптомы
- После выбора объекта карточка не отображалась, хотя API `/web/api/units/{id}` возвращал корректные данные и в логе (`logs/web_monitoring.log`) фиксировались события `card_detail_loaded`.

## Причина
1. Функция `ensurePool` полностью очищала контейнер списка (`innerEl.innerHTML = ""`), из-за чего узел карточки удалялся из DOM и больше не получал контент.
2. В CSS карточка имела базовое значение `display:none`, поэтому даже после снятия класса `.hidden` браузер продолжал прятать блок.

## Исправление
- В `web/static/v2/app.js` карточка сохраняется перед очисткой пула и пере вставляется обратно после создания строк, что сохраняет её позицию внутри виртуализированного списка.
- В `web/static/v2/app.css` базовый стиль `display:block`, а скрытие теперь регулируется только классом `.hidden`.

В результате карточка снова появляется под выбранной строкой, настройки секций работают так же, как в карточке Wialon.
