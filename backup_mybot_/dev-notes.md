# Dev notes

## Уровень топлива

- Основной уровень берём только с датчика типа `fuel level`. Приоритет имени: `ДУТ` без суффикса, затем любые другие `fuel level`.
- Если расчёт по основному сенсору даёт число, отображаем его сразу (`format_liters` сохраняет десятые; суффикс «л» добавляется в месте вывода).
- Когда основное значение отсутствует, запускаем диагностику `ДУТ1`, `ДУТ2`, … (`value < 1` → строка «не работает» с подсказкой параметра). Если отказов нет, выводим «ДУТ не установлен».
- API-запрос `core/search_items` для юнитов выполняем с флагами `4097` (base + sensors), чтобы поле `sens.t` было доступно при выборе датчика.
